# scr — notion-sync docs site

## Goal

Docusaurus site = single source of truth (SOT) for **user-facing** docs — humans and agents.

## Decision (current phase)

- `internal/sync/agents.md.tmpl` stays **as is** — still the only doc the binary ships. Not deprecated, not generated.
- Docs site evolves **separately**. All user-facing info from `README.md` + `AGENTS.md` is ported into it.
- No sync/generation between the two yet. Revisit later (short AGENTS.md + link out, generated from site).

## Layout — mirrors `SALURBAL-Climate/salurbal-obt`

```
docusaurus/
├── go.mod                 # fences folder off from the Go module (go ./... skips it)
├── package.json           # pnpm, Docusaurus 3.10.2, docusaurus-plugin-llms
├── docusaurus.config.ts   # baseUrl /notion-sync/, docs at site root, llms.txt
├── sidebars.ts            # autogenerated from docs/
├── docs/
│   ├── index.md
│   ├── getting-started/   # install, notion-setup, quickstart
│   ├── guides/            # push
│   ├── reference/         # commands, workspace-layout, frontmatter, file-urls, metadata-files
│   └── agents.md          # for agents: AGENTS.md vs site, push guardrails
└── src/css/custom.css
.github/workflows/docusaurus-site.yml   # main-only build → gh-pages, smoke test
```

Differences from salurbal-obt: no versioned docs, no redirects, no mermaid.

## Deploy

- Push to `main` touching `docusaurus/**` → build → `gh-pages` branch (force_orphan) → smoke test.
- URL: https://drexel-uhc.github.io/notion-sync/
- **One-time manual:** Settings → Pages → Source = Deploy from branch `gh-pages` / root (after first deploy creates the branch).

## Local

```sh
cd docusaurus
pnpm install
pnpm start   # live preview
pnpm build   # what CI runs; throws on broken links
```
