# Workspace layout

*What's on disk after an import.*

The `--output` folder is a **workspace**. It holds:

- one subfolder per synced Notion **database**, with one `.md` per entry and a `_database.json`
- a `pages/` subfolder with one folder per synced **standalone page** (imported by URL, not part of a database), each with a `_page.json` and one `.md`
- an `AGENTS.md` at the root, generated by notion-sync for LLM tools

```
<workspace-root>/
├── AGENTS.md
├── <Database Title>/
│   ├── _database.json
│   └── <notion-id>.md             (one per database entry)
├── <Multi-Source Database>/
│   ├── _database.json             (top-level, no dataSourceId)
│   ├── <Source 1 Title>/
│   │   ├── _database.json         (with dataSourceId)
│   │   └── <notion-id>.md
│   └── <Source 2 Title>/
│       └── ...
└── pages/
    └── <Page Title>_<short-id>/
        ├── _page.json
        └── <Page Title>.md
```

## Filenames

- **Database entries**: `{notion-id}.md` (UUID-based). Stable — renaming the page in Notion does not change the filename. The title lives in the frontmatter, under the database's title-property name.
- **Standalone pages**: title-based filename, inside a folder named `<sanitized-title>_<8-char-id>/`.

## AGENTS.md

`AGENTS.md` is **tool-owned**: `import`, `refresh`, and `clean` rewrite it whenever its version stamp predates the running binary, and `agents-md` always rewrites it. Local edits are discarded — don't hand-edit it. See [For agents](../agents.md).
